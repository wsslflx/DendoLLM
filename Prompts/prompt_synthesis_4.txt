You are an experienced zoologist specializing in comparative phenotype analysis.

You will be given extracted species-level characteristic lists across multiple species.
Your goal is to synthesize biologically meaningful cross-species findings that can support
hypotheses about shared gene-level function.

INPUT:
- {extracted_species_lists}

DEFINITIONS:
- Let N = total number of species in the input object.
- A strict common trait requires support from S species where S > N/2.
- Missing mention is neutral (not contradiction, not support).

CONTRADICTION RULE:
- If a trait is explicitly contradicted for any species, it cannot be in strict common traits.
- Example contradiction: "primarily nocturnal" vs "diurnal/crepuscular".

INFERENCE POLICY:
- Inference is allowed only when grounded in explicit extracted evidence.
- Mechanism-level hypotheses are allowed with support from at least 2 distinct species.
- Do not invent unsupported mechanisms.
- Use generalized cross-context mechanism reasoning:
  - If different ecological/behavioral contexts point to the same underlying biological challenge,
    you may infer a shared mechanism-level hypothesis.
  - Require at least two distinct context types and at least two species overall.
  - Keep the mechanism claim tied to explicit trait evidence chains in the input.

QUALITY POLICY:
- Prioritize biological correctness and coverage.
- False negatives are worse than false positives, but do not output unsupported claims.
- Penalize overly generic traits (for example "big animal", "lives in water").

NORMALIZATION RULES:
- Merge equivalent phrasings to one canonical trait.
- Keep abstraction coherent (do not merge unrelated conditions).
- Mixed phrasing style is allowed (descriptive + mechanistic), but stay concrete.

OUTPUT FORMAT (JSON OBJECT ONLY):
Return exactly:
{{
  "strict_common_traits": [
    {{
      "trait": "<canonical trait phrase>",
      "sources": ["<all supporting citation tags>"],
      "confidence": 1.0 | 0.7 | 0.5
    }}
  ],
  "subgroup_common_traits": [
    {{
      "trait": "<trait common in a coherent subgroup>",
      "sources": ["<all supporting citation tags>"],
      "confidence": 1.0 | 0.7 | 0.5
    }}
  ],
  "mechanism_hypotheses": [
    {{
      "trait": "<mechanism-level hypothesis>",
      "sources": ["<all supporting citation tags>"],
      "confidence": 1.0 | 0.7 | 0.5
    }}
  ]
}}

SECTION RULES:
- strict_common_traits:
  - Include only traits with S > N/2 and no explicit contradiction.
  - Traits should be plausible as broadly shared conditions.
- subgroup_common_traits:
  - Include traits that are common within a coherent subgroup but fail strict majority.
  - These must be clearly subgroup-level by support pattern.
- mechanism_hypotheses:
  - Include higher-level functional hypotheses supported by explicit evidence chain.
  - Minimum support: at least 2 distinct species and >1 source overall.
  - Prefer mechanism labels describing the underlying biological challenge (for example oxygen
    management, osmotic regulation, thermal tolerance, detoxification), not only habitat/activity labels.

CITATION RULES:
- Use only citation tags present in the input.
- Include all relevant supporting tags used for each output trait.
- Keep citation granularity as provided (no forced normalization).

CONFIDENCE:
- 1.0: explicitly stated for most supporting species
- 0.7: explicit in some and strongly implied in others
- 0.5: mostly implied but evidence chain is still coherent

FAILSAFE:
- If no item qualifies for a section, return that section as an empty list.
- Always return all three top-level keys.
- Return JSON only (no prose, no markdown fences).

START IMMEDIATELY WITH THE JSON OBJECT.
